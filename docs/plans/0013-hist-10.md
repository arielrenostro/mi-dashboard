# HIST-10: Atualizar main.py — Remover Conexões Diretas e Instanciar EcuSession

## Contexto

`main.py` é o ponto de fiação de todo o sistema. Atualmente ele:
1. Conecta `ecu_connection.emitter` diretamente a `signal_processor.process_line` e `log_writer.write` — fora do Bus.
2. Instancia `EcuConnectionThread` e chama `start()` nela.
3. Tem `LambdaToggle`, `KeyHoldDetector` e `EventMarker` comentados.
4. Consome `ECU_COMMAND_REQUESTED` para chamar `get_ecu_connection().send_command()`.

Após as histórias anteriores, essas conexões diretas e o `EcuConnectionThread` externo devem ser removidos.

## História de Usuário

Como desenvolvedor, quero um `main.py` limpo que instancie `EcuSession` (com o Transport correto), inicie os componentes via Bus e não contenha conexões diretas entre componentes, para que o wiring reflita a nova arquitetura.

## Requisitos Funcionais

- RF01: Instanciar `SerialTransport` ou `MockEcuTransport` baseado em `config.connection.mock`.
- RF02: Instanciar `EcuSession(transport)` e chamá-la em vez de `register_ecu_connection` + `EcuConnectionThread`.
- RF03: Remover as conexões diretas `ecu_connection.emitter.connect(signal_processor.process_line)` e `ecu_connection.emitter.connect(log_writer.write)`.
- RF04: Remover a subscrição de `ECU_COMMAND_REQUESTED` que chama `get_ecu_connection().send_command()` — a Session processa comandos internamente após HIST-02.
- RF05: Remover a subscrição de `EVENT_MARK_REQUESTED` para `log_writer.set_event_pending()` — o LogWriter auto-subscreve após HIST-06.
- RF06: Reativar `LambdaToggle`, `KeyHoldDetector` e `EventMarker` (estavam comentados).
- RF07: Instanciar `LambdaLoopStateProcessor()` para que ele auto-inscreva no Bus.
- RF08: Chamar `ecu_session.start()` em vez de `get_ecu_connection_thread().start()`.
- RF09: No shutdown, chamar `ecu_session.stop()` em vez de `get_ecu_connection_thread().stop()`.
- RF10: A subscrição de `SIGNALS_RECEIVED → vehicle_state.update(e.data)` deve permanecer em `main.py` (ou ser movida para `VehicleState.__init__()` se preferido — ver Notas).

## Requisitos Não Funcionais

- RNF01: `main.py` deve permanecer o único local de instanciação e wiring — não distribuir em módulos internos.
- RNF02: A ordem de instanciação deve garantir `QApplication` antes de qualquer `QObject` (EventBus, AlarmProcessor, etc.).

## Especificações Técnicas

### Estrutura do novo main.py

```python
def main():
    setup_logging()
    logger.info("Starting app")

    app = QApplication(sys.argv)

    # 1. LogWriter (auto-subscreve ECU_MESS_FRAME e EVENT_MARK_REQUESTED via Bus)
    log_writer = LogWriter(log_file=...)

    # 2. AlarmProcessor (inicia QTimer interno)
    alarm_processor = AlarmProcessor(config.alarm.sound)
    alarm_processor.start()

    # 3. SignalProcessor (auto-subscreve ECU_MESS_FRAME via Bus)
    signal_processor = SignalProcessor()

    # 4. VehicleState update: manter subscrição em SIGNALS_RECEIVED
    event_bus.subscribe(
        event_type=AppEventType.SIGNALS_RECEIVED,
        callback=lambda e: vehicle_state.update(e.data),
    )

    # 5. LambdaLoopStateProcessor (auto-subscreve SIGNALS_RECEIVED e ECU_COMMAND_RESPONSE)
    lambda_state = LambdaLoopStateProcessor()

    # 6. ECU Transport + Session
    if config.connection.mock != '':
        from app.ecu_connection.mock_transport import MockEcuTransport
        transport = MockEcuTransport(config.connection.mock)
    else:
        from app.ecu_connection.transport import SerialTransport
        transport = SerialTransport(config.connection.port, config.connection.baudrate)

    from app.ecu_connection.session import EcuSession
    ecu_session = EcuSession(transport)
    register_ecu_session(ecu_session)

    # 7. UI
    event_marker = EventMarker(config.alarm.sound)
    app_window = AppWindow(signal_processor)
    app_window.show()

    # 8. Lambda Toggle (hold key)
    lambda_toggle = LambdaToggle(config.ve_calibration.ve_sound)
    space_detector = KeyHoldDetector(Qt.Key.Key_Space, 2000)
    space_detector.triggered.connect(lambda_toggle.handle_trigger)
    app_window.key_event.connect(space_detector.on_key_pressed)
    app_window.key_released.connect(space_detector.on_key_released)
    app_window.key_event.connect(event_marker.handle_key)

    # 9. Start ECU
    ecu_session.start()

    app.exec()

    app_window.close()
    alarm_processor.stop()
    ecu_session.stop()
```

### LambdaToggle e ECU_COMMAND_REQUESTED

O `LambdaToggle.handle_trigger()` atualmente publica `EcuCommandRequestedEvent` no Bus. Com a Session expondo `open_loop()` e `close_loop()`, o `LambdaToggle` pode:
- **Opção A**: Continuar publicando `ECU_COMMAND_REQUESTED` no Bus, e a Session se inscreve para receber e delegar para `open_loop()/close_loop()`.
- **Opção B**: `LambdaToggle.handle_trigger()` chama `get_ecu_session().open_loop()` ou `close_loop()` diretamente.

Usar Opção B — mais simples, elimina um nível de indireção.
