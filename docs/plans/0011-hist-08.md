# História 08 — LogWriter com buffer D01+D02

**ID:** 0011  
**Área:** LogWriter  
**Fase:** 4

---

## Contexto

O `LogWriter` atual recebe a linha combinada `#D01;...;#D02;...` via conexão direta ao `emitter` do `EcuConnectionThread`. Ele filtra apenas linhas `#D01` e escreve diretamente.

Na arquitetura alvo, cada frame chega separadamente como `EcuMessFrameEvent`. O LogWriter deve se inscrever no bus, acumular D01 e D02 num buffer interno, e gravar a linha CSV apenas quando ambos os frames estiverem disponíveis.

---

## História de Usuário

Como sistema, quero que o LogWriter se inscreva no bus para `ECU_MESS_FRAME`, acumule D01 e D02 num buffer interno, e grave a linha CSV apenas quando o par estiver completo, para que o log contenha dados de ambos os frames sem depender da conexão direta com o EcuConnectionThread.

---

## Requisitos Funcionais

- `LogWriter.__init__` deve se inscrever em `AppEventType.ECU_MESS_FRAME` via bus.
- Buffer interno `_pending: dict[str, str]` — guarda a última linha de cada `frame_id`.
- Ao receber `EcuMessFrameEvent`:
  - Armazena `_pending[frame_id] = event.line`
  - Se `"D01"` e `"D02"` estiverem presentes em `_pending`:
    - Monta campos CSV: `[timestamp, event_flag] + D01_fields + D02_fields`
    - Envia para Worker thread via fila interna existente
    - Limpa `_pending`
- `set_event_pending()` e `_event_pending` continuam funcionando sem alteração.
- Método `write(line: str)` deve ser removido.
- Conexão em `main.py` `get_ecu_connection().emitter.connect(log_writer.write)` deve ser removida.

---

## Requisitos Não-Funcionais

- O método `_on_mess_frame` é chamado via Qt signal (main thread) — sem locks necessários.
- A Worker thread interna do LogWriter não muda — apenas a origem dos dados muda.
- Se D02 não chegar (ex: mock que só emite D01), o log não grava — comportamento aceitável e documentado.

---

## Especificação Técnica

### Estrutura do LogWriter após migração:

```python
class LogWriter(QObject):
    def __init__(self, log_file: str):
        super().__init__()
        self._event_pending = False
        self._pending: dict[str, str] = {}   # novo: buffer por frame_id

        # Worker thread interna (sem alteração)
        self._worker = Worker(log_file)
        self._worker_thread = QThread()
        self._worker.moveToThread(self._worker_thread)
        self._worker_thread.start()
        self.task = pyqtSignal(...)  # mantido

        # Substituir write() por _on_mess_frame()
        event_bus.subscribe(AppEventType.ECU_MESS_FRAME, self._on_mess_frame)
        event_bus.subscribe(AppEventType.EVENT_MARK_REQUESTED, lambda _: self.set_event_pending())

    def set_event_pending(self) -> None:
        self._event_pending = True

    def _on_mess_frame(self, event: EcuMessFrameEvent) -> None:
        self._pending[event.frame_id] = event.line

        if "D01" not in self._pending or "D02" not in self._pending:
            return

        d01_parts = self._pending["D01"].split(";")[1:]  # excluir "#D01"
        d02_parts = self._pending["D02"].split(";")[1:]  # excluir "#D02"

        timestamp = datetime.now().isoformat()
        event_flag = "MARK" if self._event_pending else ""
        self._event_pending = False

        row = [timestamp, event_flag] + d01_parts + d02_parts
        self._enqueue_row(row)   # enviar para Worker thread (lógica existente)
        self._pending.clear()
```

### Impacto em `main.py`

Remover a linha:
```python
get_ecu_connection().emitter.connect(log_writer.write)
```

A subscrição em `EVENT_MARK_REQUESTED` pode ser migrada para dentro do `LogWriter.__init__`, eliminando também:
```python
event_bus.subscribe(
    event_type=AppEventType.EVENT_MARK_REQUESTED,
    callback=lambda _: log_writer.set_event_pending(),
)
```
