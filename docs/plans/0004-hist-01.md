# HIST-01: Criar EcuTransport — Camada de Transporte Serial Abstrata

## Contexto

Atualmente `EcuConnectionSerial` mistura responsabilidades de transporte (abrir/fechar porta, `readline`, `writeline`) com responsabilidades de protocolo (interpretar prefixos `#D01`/`#D02`, handshake, retry). Para separar essas responsabilidades e permitir substituição de mock sem duplicar lógica de protocolo, é necessária uma camada de transporte pura.

## História de Usuário

Como desenvolvedor do projeto, quero uma camada de transporte isolada que saiba apenas abrir/fechar a conexão e ler/escrever bytes, para que a camada de protocolo (EcuSession) possa ser testada e substituída sem acoplar-se ao hardware serial.

## Requisitos Funcionais

- RF01: Existir uma classe abstrata `EcuTransport` com interface `open()`, `close()`, `readline() -> str`, `writeline(line: str) -> None`, `is_open() -> bool`.
- RF02: Existir `SerialTransport(EcuTransport)` que envolve `serial.Serial`, implementando `readline()` via `serial.readline().decode("utf-8").strip()` e `writeline()` via `serial.write(f'{line}\n'.encode("utf-8"))`.
- RF03: Existir `MockTransport(EcuTransport)` que simula uma fila de linhas a serem lidas e uma fila de linhas escritas, para uso em testes e no modo mock.
- RF04: `SerialTransport` deve aceitar `port: str` e `baudrate: int` no construtor, repassando para `serial.Serial`.
- RF05: `MockTransport` deve expor `push_read_line(line: str)` para enfileirar linhas que `readline()` retornará, e `get_written_lines() -> list[str]` para inspecionar o que foi escrito.
- RF06: `MockTransport.readline()` deve bloquear (com timeout configurável) quando a fila estiver vazia, retornando string vazia após timeout — equivalente ao comportamento do `serial.Serial(timeout=1)`.

## Requisitos Não Funcionais

- RNF01: `EcuTransport` não deve importar nada de `app/` — somente stdlib e `pyserial`.
- RNF02: `SerialTransport` deve configurar `timeout=1` e `write_timeout=1` por padrão.
- RNF03: `MockTransport` deve ser thread-safe (usar `queue.Queue` internamente).

## Especificações Técnicas

### Localização

### Interfaces

```python
from abc import ABC, abstractmethod

class EcuTransport(ABC):
    @abstractmethod
    def open(self) -> None: ...

    @abstractmethod
    def close(self) -> None: ...

    @abstractmethod
    def readline(self) -> str:
        """Blocks until a line is available or timeout. Returns '' on timeout."""
        ...

    @abstractmethod
    def writeline(self, line: str) -> None: ...

    @abstractmethod
    def is_open(self) -> bool: ...


class SerialTransport(EcuTransport):
    def __init__(self, port: str, baudrate: int):
        import serial
        self._serial = serial.Serial(baudrate=baudrate, timeout=1, write_timeout=1)
        self._serial.port = port

    def open(self) -> None:
        self._serial.open()

    def close(self) -> None:
        self._serial.close()

    def readline(self) -> str:
        return self._serial.readline().decode("utf-8").strip()

    def writeline(self, line: str) -> None:
        self._serial.write(f'{line}\n'.encode("utf-8"))

    def is_open(self) -> bool:
        return self._serial.is_open


class MockTransport(EcuTransport):
    def __init__(self, read_timeout: float = 1.0):
        import queue
        self._read_queue: queue.Queue[str] = queue.Queue()
        self._written: list[str] = []
        self._open = False
        self._timeout = read_timeout

    def open(self) -> None:
        self._open = True

    def close(self) -> None:
        self._open = False

    def readline(self) -> str:
        import queue
        try:
            return self._read_queue.get(timeout=self._timeout)
        except queue.Empty:
            return ""

    def writeline(self, line: str) -> None:
        self._written.append(line)

    def is_open(self) -> bool:
        return self._open

    def push_read_line(self, line: str) -> None:
        """Enqueue a line to be returned by the next readline() call."""
        self._read_queue.put(line)

    def get_written_lines(self) -> list[str]:
        return list(self._written)
```

### Impacto no código existente

`EcuConnectionSerial` atual tem `self.serial = serial.Serial(...)` inline. Após esta história, `EcuSession` (HIST-02) usará `SerialTransport`. `EcuConnectionSerial` pode ser mantido temporariamente sem alteração até HIST-02 ser concluído.
