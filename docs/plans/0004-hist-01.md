# História 01 — Novos Eventos no EventBus

**ID:** 0004  
**Área:** EventBus Refactoring  
**Fase:** 1 (independente)

---

## Contexto

A arquitetura alvo requer que `EcuSession` publique eventos de frame e de resposta de comando no bus central. Atualmente os eventos `ECU_MESS_FRAME`, `ECU_COMMAND_SENT`, `ECU_COMMAND_RESPONSE` e `ECU_CONNECTION_STATUS_CHANGED` não existem. Sem eles, nenhum assinante (SignalProcessor, LogWriter) pode migrar para a nova arquitetura.

Esta é a história mais independente do projeto: apenas adiciona código novo sem alterar comportamento existente.

---

## História de Usuário

Como desenvolvedor, quero que o EventBus suporte os novos tipos de eventos da arquitetura alvo para que SignalProcessor, LogWriter e EcuSession possam se comunicar via bus sem acoplamento direto.

---

## Requisitos Funcionais

- `AppEventType` deve conter os valores `ECU_MESS_FRAME`, `ECU_COMMAND_SENT`, `ECU_COMMAND_RESPONSE` e `ECU_CONNECTION_STATUS_CHANGED`.
- Cada novo tipo deve ter uma dataclass frozen correspondente em `app_events.py`.
- `_EventBusQObject` deve ter um `pyqtSignal(object)` para cada novo tipo.
- `_SIGNAL_ATTR` deve mapear cada novo `AppEventType` para o nome do atributo.
- Código existente que usa `AppEventType` e `event_bus` não deve quebrar.

---

## Requisitos Não-Funcionais

- Thread safety: `pyqtSignal.emit()` já é thread-safe — sem necessidade de locks adicionais.
- Nenhum arquivo fora de `app/event/` deve ser modificado nesta história.

---

## Especificação Técnica

### `app/event/app_events.py` — adicionar ao final do arquivo:

```python
@dataclass(frozen=True)
class EcuMessFrameEvent(AppEvent):
    """Publicado pela Reader thread da EcuSession para cada frame recebido."""
    type_: AppEventType = field(default=AppEventType.ECU_MESS_FRAME, init=False)
    frame_id: str = ""   # "D01", "D02", "D03"
    line: str = ""       # linha completa: "#D01;v1;v2;..."

@dataclass(frozen=True)
class EcuCommandSentEvent(AppEvent):
    """Publicado pela EcuSession ao enviar qualquer comando."""
    type_: AppEventType = field(default=AppEventType.ECU_COMMAND_SENT, init=False)
    command: Any = None
    args: Any = None

@dataclass(frozen=True)
class EcuCommandResponseEvent(AppEvent):
    """Publicado pela Reader thread para linhas que não são frames de medição."""
    type_: AppEventType = field(default=AppEventType.ECU_COMMAND_RESPONSE, init=False)
    line: str = ""

@dataclass(frozen=True)
class EcuConnectionStatusChangedEvent(AppEvent):
    """Publicado pela EcuSession quando o status de conexão muda."""
    type_: AppEventType = field(default=AppEventType.ECU_CONNECTION_STATUS_CHANGED, init=False)
    status: Any = None   # EcuConnectionStatus enum (a ser definido em session.py)
```

### `app/event/app_events.py` — adicionar ao enum `AppEventType`:

```python
ECU_MESS_FRAME                  = auto()
ECU_COMMAND_SENT                = auto()
ECU_COMMAND_RESPONSE            = auto()
ECU_CONNECTION_STATUS_CHANGED   = auto()
```

### `app/event/bus.py` — adicionar em `_EventBusQObject`:

```python
ecu_mess_frame                = pyqtSignal(object)
ecu_command_sent              = pyqtSignal(object)
ecu_command_response          = pyqtSignal(object)
ecu_connection_status_changed = pyqtSignal(object)
```

### `app/event/bus.py` — adicionar em `_SIGNAL_ATTR`:

```python
AppEventType.ECU_MESS_FRAME:                  "ecu_mess_frame",
AppEventType.ECU_COMMAND_SENT:                "ecu_command_sent",
AppEventType.ECU_COMMAND_RESPONSE:            "ecu_command_response",
AppEventType.ECU_CONNECTION_STATUS_CHANGED:   "ecu_connection_status_changed",
```
