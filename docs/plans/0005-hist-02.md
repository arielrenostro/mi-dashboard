# História 02 — Campos frame e frame_index em Signal

**ID:** 0005  
**Área:** Signal Refactoring  
**Fase:** 1 (independente)

---

## Contexto

Atualmente cada `Signal` usa um campo `"index"` com posição absoluta no frame combinado `#D01;...;#D02;...` após split por `;`. Isso é frágil: se o número de campos de D01 mudar, todos os índices de D02 ficam errados.

A arquitetura alvo separa a responsabilidade: cada sinal deve declarar de qual frame vem (`"frame": "D01"`) e qual é sua posição dentro daquele frame individual (`"frame_index": 1`). O campo `"index"` deve ser mantido temporariamente para backward-compatibility durante a migração do `SignalProcessor`.

Esta história é backward-compatible: adiciona campos sem remover `"index"`, logo não quebra o SignalProcessor atual.

---

## História de Usuário

Como desenvolvedor, quero que cada Signal declare explicitamente seu frame de origem e índice dentro desse frame, para que o SignalProcessor possa processar cada frame de forma independente sem depender de posições absolutas num frame combinado.

---

## Requisitos Funcionais

- Cada sinal não-calculado deve ter `"frame"` (string, ex: `"D01"`) e `"frame_index"` (int, posição a partir de 1 após o prefixo `#Dxx`).
- O campo `"index"` deve ser mantido com o mesmo valor atual (backward-compat).
- Sinais com `"calculated": True` (`VE_LAMBDA`, `POWER`, `TORQUE`) não precisam de `"frame"` nem `"frame_index"`.
- O comportamento do app não muda com esta história isolada.

---

## Requisitos Não-Funcionais

- Nenhuma mudança de comportamento em runtime.
- Código deve continuar compatível com o SignalProcessor atual (que usa `"index"`).

---

## Especificação Técnica

### Regra de mapeamento (a aplicar enquanto fronteira D01/D02 não for confirmada)

Todos os sinais atualmente com `"index"` de 1 a 33 são mapeados como `"frame": "D01"` com `"frame_index"` igual ao valor atual de `"index"`. Isso é funcionalmente equivalente ao comportamento atual e seguro para implementação incremental (ver Risco R3 da spec).

### Exemplo de sinal após modificação:

```python
RPM = {
    "name": "RPM",
    "frame": "D01",        # novo
    "frame_index": 1,      # novo
    "index": 1,            # mantido para backward-compat
    "converter": lambda x: int(x),
    ...
}
```
