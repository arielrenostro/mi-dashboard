# História 09 — AlarmProcessor: de QThread para QObject+QTimer

**ID:** 0012  
**Área:** AlarmProcessor  
**Fase:** 4

---

## Contexto

O `AlarmProcessor` atual é um `QThread` com um loop de polling que verifica `vehicle_state.is_any_alarm_firing()` a cada 100ms e emite sinais `_play_requested`/`_stop_requested` via `QueuedConnection` para garantir que `QMediaPlayer` opere na main thread.

A arquitetura alvo remove a thread de polling: o `AlarmProcessor` passa a ser um `QObject` na main thread, com um `QTimer(100ms)` substituindo o loop. Como tudo ocorre na main thread, a `QueuedConnection` intermediária e os sinais `_play_requested`/`_stop_requested` tornam-se desnecessários.

---

## História de Usuário

Como sistema, quero que o AlarmProcessor use um QTimer em vez de uma QThread de polling, para simplificar o código, eliminar riscos de thread affinity do QMediaPlayer e reduzir o número de threads no processo.

---

## Requisitos Funcionais

- `AlarmProcessor` herda de `QObject` (não mais `QThread`).
- Um `QTimer` com intervalo de 100ms substitui o loop `run()`.
- O `QTimer` chama `_update_audio_state()` que verifica `vehicle_state.is_any_alarm_firing()` e chama `player.play()` / `player.stop()` diretamente.
- `process_signals()` permanece com a lógica atual de detecção de alarme e publicação de `AlarmFiredEvent`.
- `stop()` para o `QTimer` e chama `player.stop()`.
- Remover: `run()`, `_play_requested`, `_stop_requested`, `running`.
- Remover as conexões `QueuedConnection` para `_play_requested` e `_stop_requested`.
- `QMediaPlayer` e `QAudioOutput` continuam no `__init__`.

---

## Requisitos Não-Funcionais

- `AlarmProcessor` deve ser instanciado **após** `QApplication()` para garantir thread affinity correta do `QMediaPlayer`.
- `QTimer` opera na main thread por padrão quando `AlarmProcessor` é instanciado na main thread — sem necessidade de `QueuedConnection`.
- `_handle_status` (EndOfMedia → replay) continua funcionando sem alteração.

---

## Especificação Técnica

### `app/alarm/processor.py` — versão alvo:

```python
import logging
import time
from typing import Dict

from PyQt6.QtCore import QObject, QTimer, QUrl
from PyQt6.QtMultimedia import QMediaPlayer, QAudioOutput

from app.event.app_events import AppEventType, AlarmFiredEvent, SignalsReceivedEvent
from app.event.bus import event_bus
from app.masterinjection.signal import Signal, ParsedSignal
from app.state.state import vehicle_state

logger = logging.getLogger(__name__)


class AlarmProcessor(QObject):

    def __init__(self, sound: str):
        super().__init__()

        self.audio_output = QAudioOutput()
        self.audio_output.setVolume(1.0)

        self.player = QMediaPlayer()
        self.player.setAudioOutput(self.audio_output)
        self.player.setSource(QUrl.fromLocalFile(sound))
        self.player.mediaStatusChanged.connect(self._handle_status)

        self._alarm_until: Dict[Signal, float] = {}

        event_bus.subscribe(AppEventType.SIGNALS_RECEIVED, self._on_signals_received)

        self._timer = QTimer()
        self._timer.setInterval(100)
        self._timer.timeout.connect(self._update_audio_state)
        self._timer.start()

        self._is_playing = False

    def _on_signals_received(self, event: SignalsReceivedEvent):
        self.process_signals(event.data)

    def _update_audio_state(self):
        should_play = vehicle_state.is_any_alarm_firing()
        if should_play and not self._is_playing:
            self.player.play()
            self._is_playing = True
        elif not should_play and self._is_playing:
            self.player.stop()
            self._is_playing = False

    def stop(self):
        self._timer.stop()
        self.player.stop()
        self._is_playing = False

    def process_signals(self, signals: Dict[Signal, ParsedSignal]):
        now = time.time()
        for signal, data in signals.items():
            alarm = signal.value["alarm"]
            duration = alarm.get("duration_s", 2.0)

            in_alarm = self._check_in_alarm(alarm, data)
            vehicle_state.set_alarm(signal, in_alarm)

            if in_alarm:
                until = self._alarm_until.get(signal, 0.0)
                if now >= until:
                    new_until = now + duration
                    self._alarm_until[signal] = new_until
                    event_bus.publish(AlarmFiredEvent(signal=signal, until=new_until))
            else:
                self._alarm_until.pop(signal, None)

    @staticmethod
    def _check_in_alarm(alarm: dict, data: ParsedSignal) -> bool:
        min_ = alarm["min"] if alarm["min"] is None or isinstance(alarm["min"], (int, float)) else alarm["min"](data.value)
        max_ = alarm["max"] if alarm["max"] is None or isinstance(alarm["max"], (int, float)) else alarm["max"](data.value)

        if min_ is not None and data.value < min_:
            return alarm["enabled"]
        if max_ is not None and data.value > max_:
            return alarm["enabled"]
        return False

    def _handle_status(self, status):
        if status == QMediaPlayer.MediaStatus.EndOfMedia:
            if vehicle_state.is_any_alarm_firing():
                self.player.play()
```

### Impacto em `main.py`

Remover:
```python
alarm_processor.start()
```

O `QTimer` inicia automaticamente no `__init__`. O `stop()` continua sendo chamado ao fechar o app.
