# História 03 — EcuTransport ABC

**ID:** 0006  
**Área:** ECU Communication Layer  
**Fase:** 1 (independente)

---

## Contexto

A arquitetura atual mistura lógica de protocolo, transporte físico e threading em `EcuConnectionSerial` e `EcuConnectionMock`. A separação entre camada de transporte (como os bytes trafegam) e camada de sessão (protocolo, handshake, threads) é necessária para que `SerialTransport` e `MockTransport` possam ser trocados sem alterar a lógica de sessão.

O `EcuTransport` é o contrato mínimo que qualquer transporte deve cumprir. É uma classe puramente abstrata sem dependências do projeto — pode ser criada de forma totalmente independente.

---

## História de Usuário

Como desenvolvedor, quero uma interface abstrata `EcuTransport` para que `SerialTransport` e `MockTransport` possam ser implementados de forma intercambiável, permitindo usar serial real em produção e replay de CSV em desenvolvimento sem alterar a EcuSession.

---

## Requisitos Funcionais

- `EcuTransport` deve ser uma ABC com os métodos `connect()`, `disconnect()`, `readline()`, `write()` e `is_connected()`.
- Todos os métodos devem ter docstrings explicando o comportamento esperado.
- `readline()` deve ser bloqueante com timeout configurável e retornar string sem newline.
- `write(line: str)` deve escrever a linha com `\n` ao final.

---

## Requisitos Não-Funcionais

- O arquivo não deve importar nada do projeto (apenas stdlib e abc).
- Sem efeitos colaterais ao importar o módulo.

---

## Especificação Técnica

### `app/ecu_connection/transport.py` — criar do zero:

```python
from abc import ABC, abstractmethod


class EcuTransport(ABC):
    """Interface abstrata para transporte físico de dados com a ECU.

    Implementações: SerialTransport (porta serial real) e MockTransport (replay CSV).
    """

    @abstractmethod
    def connect(self) -> None:
        """Abre a conexão física (abre porta serial ou inicia replay do CSV).

        Deve bloquear até a conexão estar estabelecida ou lançar exceção em caso de falha.
        """
        ...

    @abstractmethod
    def disconnect(self) -> None:
        """Fecha a conexão física de forma limpa."""
        ...

    @abstractmethod
    def readline(self) -> str:
        """Leitura bloqueante de uma linha.

        Retorna a linha sem o caractere de newline final.
        Retorna string vazia se o timeout expirar sem dados.
        Timeout deve ser configurável na implementação concreta (sugestão: 1-3 segundos).
        """
        ...

    @abstractmethod
    def write(self, line: str) -> None:
        """Escreve uma linha no transporte, adicionando '\\n' ao final.

        Deve ser thread-safe ou documentar que não é.
        """
        ...

    @abstractmethod
    def is_connected(self) -> bool:
        """Retorna True se a conexão física está estabelecida."""
        ...
```
