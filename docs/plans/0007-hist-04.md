# História 04 — SerialTransport

**ID:** 0007  
**Área:** ECU Communication Layer  
**Fase:** 2

---

## Contexto

A lógica de conexão serial (abertura de porta, timeout, readline, write) está atualmente embutida em `EcuConnectionSerial` junto com lógica de protocolo e threading. O `SerialTransport` extrai apenas a parte de transporte físico para uma classe dedicada, implementando a interface `EcuTransport` definida na História 03.

`EcuConnectionSerial` continuará funcionando durante a transição — o `SerialTransport` será usado pela nova `EcuSession` (História 06).

---

## História de Usuário

Como desenvolvedor, quero um `SerialTransport` que encapsula apenas a comunicação serial via `pyserial`, para que a `EcuSession` possa usar serial real sem conhecer os detalhes de abertura de porta e timeouts.

---

## Requisitos Funcionais

- `SerialTransport` implementa `EcuTransport`.
- `connect()` abre a porta serial com o baud rate configurado e timeout de 3 segundos.
- `disconnect()` fecha a porta se estiver aberta.
- `readline()` lê uma linha da porta serial, decodifica UTF-8 e retorna sem `\n`. Retorna `""` em timeout.
- `write(line: str)` escreve a linha com `\n` codificada em UTF-8, de forma thread-safe (usar `threading.Lock` interno).
- `is_connected()` retorna `True` se a porta estiver aberta.
- Em caso de exceção de I/O em `readline()` ou `write()`, deve relançar para que a `EcuSession` trate.

---

## Requisitos Não-Funcionais

- `write()` deve ser thread-safe (Reader thread e handshake podem escrever concorrentemente).
- Timeout de `readline()` configurável (padrão: 3 segundos).
- Não deve logar em nível `DEBUG` para cada byte — apenas eventos de conexão/desconexão.

---

## Especificação Técnica

### `app/ecu_connection/serial_transport.py` — criar do zero:

```python
import logging
import threading

import serial

from app.ecu_connection.transport import EcuTransport

logger = logging.getLogger(__name__)


class SerialTransport(EcuTransport):
    """Transporte físico via porta serial usando pyserial."""

    def __init__(self, port: str, baudrate: int, timeout: float = 3.0):
        self._port = port
        self._baudrate = baudrate
        self._timeout = timeout
        self._serial: serial.Serial | None = None
        self._lock = threading.Lock()

    def connect(self) -> None:
        logger.info("SerialTransport: abrindo porta %s @ %d baud", self._port, self._baudrate)
        self._serial = serial.Serial(
            port=self._port,
            baudrate=self._baudrate,
            timeout=self._timeout,
        )
        logger.info("SerialTransport: porta %s aberta", self._port)

    def disconnect(self) -> None:
        if self._serial and self._serial.is_open:
            self._serial.close()
            logger.info("SerialTransport: porta %s fechada", self._port)
        self._serial = None

    def readline(self) -> str:
        if not self._serial or not self._serial.is_open:
            return ""
        raw = self._serial.readline()
        return raw.decode("utf-8", errors="replace").strip()

    def write(self, line: str) -> None:
        if not self._serial or not self._serial.is_open:
            raise IOError("SerialTransport: porta não está aberta")
        with self._lock:
            self._serial.write((line + "\n").encode("utf-8"))

    def is_connected(self) -> bool:
        return self._serial is not None and self._serial.is_open
```
