# HIST-07: Desacoplar VehicleState do Emitter Direto — Migrar para EventBus

## Contexto

`VehicleState` possui um `_VehicleStateEmitter` interno (QObject com `pyqtSignal`) que é conectado diretamente em `VeCalibrationScreen.__init__()`. Isso viola o princípio de "tudo pelo EventBus" e cria acoplamento entre o estado global e a tela. Adicionalmente, `ALARM_DURATION = 2` é hardcoded em `state.py`, ignorando o `duration_s` por sinal definido em `AlarmProcessor` — um bug real.

## História de Usuário

Como desenvolvedor, quero que o `VehicleState` publique mudanças de mapa/breakpoints via `VEHICLE_STATE_CHANGED` no EventBus em vez de usar um emitter interno, e que o estado de alarme use a duração por sinal definida no `Signal` enum, para eliminar acoplamento direto e corrigir o bug de duração de alarme.

## Requisitos Funcionais

- RF01: `VehicleState.set_rpm_breakpoints()` deve publicar `VehicleStateChangedEvent` no EventBus em vez de chamar `self.emitter.emit()`.
- RF02: `VehicleState.set_map_breakpoints()` deve publicar `VehicleStateChangedEvent` no EventBus.
- RF03: `VehicleState.set_ve_map()` deve publicar `VehicleStateChangedEvent` no EventBus.
- RF04: `_VehicleStateEmitter` e a propriedade `emitter` em `VehicleState` devem ser removidos após VeCalibrationScreen migrar (HIST-08).
- RF05: Corrigir o bug de `ALARM_DURATION`: `set_alarm(signal, active, until: float)` deve aceitar o timestamp `until` calculado pelo `AlarmProcessor` e armazená-lo em vez de recalcular com `ALARM_DURATION`.
- RF06: `is_alarm_firing(signal)` e `is_any_alarm_firing()` devem usar o `until` armazenado por sinal em vez de `time.time() - last < ALARM_DURATION`.
- RF07: `ALARM_DURATION` e o mecanismo de `_alarm_timestamps` baseado em timestamp de início devem ser substituídos por `_alarm_until: dict` baseado em timestamp de fim.

## Requisitos Não Funcionais

- RNF01: A importação de `event_bus` em `VehicleState` é segura estruturalmente (sem ciclo). Porém, o singleton `vehicle_state = VehicleState()` no módulo pode ser instanciado antes do `QApplication`. Solução: importar `event_bus` dentro dos métodos (`set_rpm_breakpoints`, etc.) em vez de no módulo global — lazy import.
- RNF02: Thread safety: as publicações no Bus devem ocorrer dentro do `with self._lock` para garantir consistência, mas o `event_bus.publish()` usa `pyqtSignal.emit()` que é thread-safe.
- RNF03: `app/state/event.py` (`EventType`, `VehicleStateChangeEvent`) deve ser mantido por compatibilidade até `VeCalibrationScreen` migrar (HIST-08). Após HIST-08, pode ser removido (HIST-11).

## Especificações Técnicas

### Correção da assinatura de set_alarm

```python
# Antes
def set_alarm(self, signal, active: bool) -> None:
    with self._lock:
        if active:
            self._alarm_timestamps[signal] = time.time()

# Depois
def set_alarm(self, signal, active: bool, until: float = 0.0) -> None:
    with self._lock:
        if active and until > 0:
            self._alarm_until[signal] = until
        elif active:
            # Fallback: usar ALARM_DURATION se until não for fornecido
            self._alarm_until[signal] = time.time() + ALARM_DURATION
        else:
            self._alarm_until.pop(signal, None)
```

```python
# Antes
def is_alarm_firing(self, signal) -> bool:
    with self._lock:
        last = self._alarm_timestamps.get(signal)
        return last is not None and (time.time() - last) < ALARM_DURATION

# Depois
def is_alarm_firing(self, signal) -> bool:
    with self._lock:
        until = self._alarm_until.get(signal, 0.0)
        return time.time() < until

def is_any_alarm_firing(self) -> bool:
    with self._lock:
        now = time.time()
        return any(now < until for until in self._alarm_until.values())
```

### Publicação via EventBus

```python
def set_rpm_breakpoints(self, breakpoints: list[int]) -> None:
    with self._lock:
        self._rpm_breakpoints = breakpoints
    # Publicar fora do lock para evitar deadlock
    from app.event.bus import event_bus
    from app.event.app_events import VehicleStateChangedEvent
    from app.state.event import EventType
    event_bus.publish(VehicleStateChangedEvent(
        change_type=EventType.RPM_BREAKPOINTS,
        args=(breakpoints,)
    ))
```

O mesmo padrão para `set_map_breakpoints` e `set_ve_map`.

### Remoção do emitter interno

```python
# Remover após HIST-08:
class _VehicleStateEmitter(QObject):
    signal = pyqtSignal(VehicleStateChangeEvent)

@property
def emitter(self):
    ...
```

Por ora, manter o emitter mas adicionar log deprecated quando `emitter` for acessado:
```python
@property
def emitter(self):
    import warnings
    warnings.warn("vehicle_state.emitter é deprecated — usar VEHICLE_STATE_CHANGED via EventBus", DeprecationWarning)
    if self._emitter is None:
        self._emitter = _VehicleStateEmitter()
    return self._emitter.signal
```

### Mudança em AlarmProcessor (coordenado)

Em `AlarmProcessor.process_signals()`, mudar a chamada:
```python
# Antes
vehicle_state.set_alarm(signal, in_alarm)

# Depois
vehicle_state.set_alarm(signal, in_alarm, until=new_until if in_alarm else 0.0)
```

`AlarmProcessor` já calcula `new_until = now + duration`. Passar esse valor para `set_alarm`.
