# História 07 — SignalProcessor com buffers por frame

**ID:** 0010  
**Área:** Signal Refactoring  
**Fase:** 4

---

## Contexto

O `SignalProcessor` atual recebe uma linha combinada `#D01;...;#D02;...` via `emitter` pyqtSignal do `EcuConnectionThread` e acessa sinais por índice absoluto. Na arquitetura alvo, cada frame chega separadamente como `EcuMessFrameEvent` no bus. O SignalProcessor deve manter buffers por frame e processar sinais usando `"frame"` e `"frame_index"` de cada Signal.

Esta história também remove o `emitter` legado do SignalProcessor e desfaz a conexão direta com `EcuConnectionThread`.

---

## História de Usuário

Como sistema, quero que o SignalProcessor se inscreva no bus para `ECU_MESS_FRAME` e processe cada frame individualmente usando os campos `frame` e `frame_index` de cada Signal, para que a separação entre D01 e D02 seja explícita e extensível.

---

## Requisitos Funcionais

- `SignalProcessor` deve se inscrever em `AppEventType.ECU_MESS_FRAME` no próprio `__init__`.
- Manter buffer interno `_frame_buffers: dict[str, list[str]]` — chave é `frame_id` (ex: `"D01"`).
- Ao receber `EcuMessFrameEvent`, atualizar o buffer do frame correspondente e processar todos os sinais disponíveis.
- Para sinais não-calculados: usar `cfg["frame"]` e `cfg["frame_index"]` para acessar o buffer correto.
- Se o buffer de um frame ainda não chegou, omitir os sinais daquele frame (dado parcial é aceitável).
- Publicar `SignalsReceivedEvent` via bus após processar.
- Remover `process_line(line: str)` (método legado que recebia frame combinado).
- Remover `emitter(dict)` pyqtSignal legado.

---

## Requisitos Não-Funcionais

- Thread safety: `_on_mess_frame` é chamado via Qt signal do bus (main thread) — sem locks necessários.
- Sinais calculados devem continuar funcionando via `cfg["value"](parsed_data)`.
- `ParsedSignal` não muda.

---

## Especificação Técnica

### `app/masterinjection/signal_processor.py` — reescrever:

```python
import logging

from PyQt6.QtCore import QObject

from app.event.app_events import (
    AppEventType,
    EcuMessFrameEvent,
    SignalsReceivedEvent,
)
from app.event.bus import event_bus
from app.masterinjection.signal import Signal, ParsedSignal

logger = logging.getLogger(__name__)


class SignalProcessor(QObject):

    def __init__(self):
        super().__init__()
        self._frame_buffers: dict[str, list[str]] = {}
        event_bus.subscribe(AppEventType.ECU_MESS_FRAME, self._on_mess_frame)

    def _on_mess_frame(self, event: EcuMessFrameEvent) -> None:
        parts = event.line.split(";")
        self._frame_buffers[event.frame_id] = parts

        parsed_data: dict[Signal, ParsedSignal] = {}

        # Sinais diretos (não calculados)
        for signal in Signal:
            cfg = signal.value
            if cfg.get("calculated"):
                continue
            frame_id = cfg.get("frame", "D01")
            frame_index = cfg.get("frame_index", cfg.get("index"))
            buf = self._frame_buffers.get(frame_id)
            if buf is None or frame_index is None or frame_index >= len(buf):
                continue
            try:
                raw = buf[frame_index]
                value = cfg["converter"](raw)
                parsed_data[signal] = ParsedSignal(signal, raw, value)
            except Exception:
                logger.debug("Erro ao converter sinal %s", signal.name, exc_info=True)
                continue

        # Sinais calculados (dependem de parsed_data)
        for signal in Signal:
            cfg = signal.value
            if not cfg.get("calculated"):
                continue
            try:
                value = cfg["value"](parsed_data)
                parsed_data[signal] = ParsedSignal(signal, value, value)
            except Exception:
                logger.debug("Erro ao calcular sinal %s", signal.name, exc_info=True)
                continue

        if parsed_data:
            event_bus.publish(SignalsReceivedEvent(data=parsed_data))
```
