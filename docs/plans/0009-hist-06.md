# História 06 — EcuSession

**ID:** 0009  
**Área:** ECU Communication Layer  
**Fase:** 3

---

## Contexto

`EcuSession` é o coração da nova arquitetura de comunicação. Ela substitui `EcuConnectionSerial`, `EcuConnectionMock` e `EcuConnectionThread` em uma única classe que:

1. Executa o handshake síncrono com a ECU.
2. Interna uma thread de leitura (Reader) que publica eventos no bus.
3. Suporta dois modos de envio de comandos: blocking (para handshake) e fire-and-forget.

`EcuSession` usa `EcuTransport` como interface de transporte, permitindo trocar Serial por Mock sem alterar a lógica de sessão.

---

## História de Usuário

Como sistema, quero que a EcuSession gerencie toda a comunicação com a ECU (handshake, leitura contínua, envio de comandos) de forma thread-safe, publicando eventos no bus central para que outros componentes reajam aos dados recebidos.

---

## Requisitos Funcionais

- `EcuSession.__init__(transport: EcuTransport)` — armazena o transporte; não conecta ainda.
- `EcuSession.start()` — executa handshake síncrono e, em caso de sucesso, inicia a Reader thread. Publica `EcuConnectionStatusChangedEvent(CONNECTED)` ao final.
- `EcuSession.stop()` — sinaliza a Reader thread para parar, aguarda join, fecha o transporte. Publica `EcuConnectionStatusChangedEvent(DISCONNECTED)`.
- `EcuSession.send_command(cmd, args=None, blocking=False)`:
  - `blocking=False`: enfileira em `_command_queue` e retorna `None`.
  - `blocking=True`: enfileira, aguarda resposta com prefixo correspondente via `threading.Event`, retorna a linha ou `None` em timeout (3s, 1 retentativa).
- Reader thread: loop contínuo chamando `transport.readline()`. Classifica a linha e publica `EcuMessFrameEvent` ou `EcuCommandResponseEvent` no bus. Drena `_command_queue` após cada frame completo. Reconecta após 3 leituras vazias consecutivas.
- Handshake: `#D50` → `#I20` → `#I21` → `#F01..#F16` → `#D01`, todos via `send_command(blocking=True)`. Breakpoints e VE parseados e gravados em `vehicle_state`.
- `EcuConnectionStatus` enum: `DISCONNECTED`, `CONNECTING`, `CONNECTED`.

---

## Requisitos Não-Funcionais

- Modo blocking nunca deve ser chamado de dentro da Reader thread (deadlock). O handshake ocorre antes da Reader iniciar — seguro por design.
- `send_command` com `blocking=True` usa `threading.Event` por comando; sem polling.
- Timeout de 3s por tentativa; 1 retentativa (2 tentativas no total). Após falha, logar `WARNING` e prosseguir.
- Reconexão: fechar transporte, publicar `DISCONNECTED`, aguardar 1s, chamar `connect()` novamente e refazer handshake.
- Thread safety: `_command_queue` é `queue.Queue` (já thread-safe); resposta blocking usa `threading.Event` por slot.

## Especificação Técnica

### Estrutura de `session.py`:

```python
import enum
import logging
import queue
import threading
import time
from dataclasses import dataclass
from typing import Any

from app.ecu_connection.transport import EcuTransport
from app.masterinjection.protocol import EcuCommand, EcuResponse
from app.state.state import vehicle_state

logger = logging.getLogger(__name__)


class EcuConnectionStatus(enum.Enum):
    DISCONNECTED = "DISCONNECTED"
    CONNECTING   = "CONNECTING"
    CONNECTED    = "CONNECTED"


@dataclass
class _PendingCommand:
    cmd: EcuCommand
    args: list | None
    blocking: bool
    event: threading.Event | None      # None para fire-and-forget
    response: list                     # [str] — preenchido pelo Reader
    expected_prefix: str | None


class EcuSession:
    def __init__(self, transport: EcuTransport) -> None:
        self._transport = transport
        self._status = EcuConnectionStatus.DISCONNECTED
        self._command_queue: queue.Queue[_PendingCommand] = queue.Queue()
        self._reader_thread: threading.Thread | None = None
        self._stop_event = threading.Event()
        self._pending_blocking: _PendingCommand | None = None   # slot único para blocking
        self._blocking_lock = threading.Lock()

    def start(self) -> None: ...  # handshake + iniciar Reader
    def stop(self) -> None: ...

    def get_status(self) -> EcuConnectionStatus:
        return self._status

    def send_command(
        self,
        cmd: EcuCommand,
        args: list | None = None,
        blocking: bool = False,
    ) -> str | None: ...

    # Métodos semânticos
    def open_loop(self) -> None:
        self.send_command(EcuCommand.LAMBDA_LOOP_OPEN)

    def close_loop(self) -> None:
        self.send_command(EcuCommand.LAMBDA_LOOP_CLOSE)

    def fetch_ve(self) -> None:
        for i in range(1, 17):
            cmd = EcuCommand[f"VE_ROW_{i}"]
            response = self.send_command(cmd, blocking=True)
            if response:
                self._parse_ve_response(cmd, response)

    def fetch_breakpoints(self) -> None:
        r = self.send_command(EcuCommand.RPM_BREAKPOINTS, blocking=True)
        if r:
            vehicle_state.set_rpm_breakpoints(self._parse_breakpoints(r))
        r = self.send_command(EcuCommand.MAP_BREAKPOINTS, blocking=True)
        if r:
            vehicle_state.set_map_breakpoints(self._parse_breakpoints(r))

    def _reader_loop(self) -> None: ...
    def _reconnect(self) -> None: ...
    def _drain_command_queue(self) -> None: ...
    def _do_handshake(self) -> None: ...
    def _parse_breakpoints(self, line: str) -> list[int]: ...
    def _parse_ve_response(self, cmd: EcuCommand, line: str) -> None: ...
    def _publish_frame(self, line: str) -> None: ...
    def _publish_response(self, line: str) -> None: ...
```

### Lógica de `_reader_loop()`:

```
zero_count = 0
while not _stop_event.is_set():
    try:
        line = transport.readline()
    except Exception:
        reconectar(); continue

    if not line:
        zero_count += 1
        if zero_count >= 3: reconectar()
        continue
    zero_count = 0

    if line.startswith(("#D01", "#D02", "#D03")):
        publicar EcuMessFrameEvent(frame_id=line[1:4], line=line)
        _drain_command_queue()
    else:
        # Verificar se é resposta para blocking pendente
        with _blocking_lock:
            if _pending_blocking and line.startswith(_pending_blocking.expected_prefix):
                _pending_blocking.response.append(line)
                _pending_blocking.event.set()
        publicar EcuCommandResponseEvent(line=line)
```

### Lógica de `send_command(blocking=True)`:

```
montar _PendingCommand com event=threading.Event()
com _blocking_lock: setar _pending_blocking
_command_queue.put(pending)
aguardar pending.event.wait(timeout=3.0)
com _blocking_lock: limpar _pending_blocking
retornar pending.response[0] se não vazio, None caso contrário
(1 retry se timeout)
```

### Parsing de resposta de breakpoints:

Formato esperado: `#I20;val1;val2;...;val16`
```python
parts = line.split(";")
return [int(p) for p in parts[1:17]]
```

### Parsing de resposta de VE row:

Formato esperado: `#F01;val1;val2;...;val16`
```python
parts = line.split(";")
values = [int(p) for p in parts[1:17]]
row_idx = cmd.value[0][2:4]  # "#F01" → "01" → 0
vehicle_state.set_ve_map(values, int(row_idx) - 1)
```
