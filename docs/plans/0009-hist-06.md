# HIST-06: Refatorar LogWriter para Acumular ECU_MESS_FRAME e Gravar via Bus

## Contexto

`LogWriter.write()` atualmente recebe a string combinada `"#D01;...;#D02;..."` via conexão direta `ecu_connection.emitter → log_writer.write` em `main.py`. Filtra apenas linhas que começam com `#D01`. Com a nova arquitetura, cada frame chega separado via `ECU_MESS_FRAME`. O LogWriter deve se inscrever no Bus, acumular D01 e aguardar D02 para gravar a linha CSV completa.

## História de Usuário

Como sistema, quero que o LogWriter se inscreva em `ECU_MESS_FRAME` e acumule D01 e D02 antes de gravar uma linha no CSV, para que o log continue correto após a separação dos frames.

## Requisitos Funcionais

- RF01: `LogWriter` se inscreve em `AppEventType.ECU_MESS_FRAME` no EventBus na inicialização.
- RF02: Ao receber `EcuMessFrameEvent(frame_id="D01", raw_line=...)`, armazenar a linha em buffer interno `_d01_buffer`.
- RF03: Ao receber `EcuMessFrameEvent(frame_id="D02", raw_line=...)` com D01 em buffer, gravar a linha CSV combinando timestamp + event + partes de D01 + partes de D02.
- RF04: Ao receber D02 sem D01 anterior, descartar (log warning).
- RF05: Ao receber novo D01 com D01 pendente (frame perdido), descartar o D01 anterior (log warning) e armazenar o novo.
- RF06: O método `write(line: str)` legado deve ser mantido por compatibilidade temporária mas marcado como deprecated.
- RF07: A subscrição em `EVENT_MARK_REQUESTED` e a lógica `_event_pending` continuam funcionando — a marcação deve ser incluída na próxima linha que for gravada.
- RF08: Remover a conexão direta `ecu_connection.emitter → log_writer.write` do `main.py` (feito em HIST-10).

## Requisitos Não Funcionais

- RNF01: Thread safety: o callback do Bus é chamado na main thread. A gravação ocorre no `Worker` em `QThread` separada via sinal Qt. Nenhuma mudança de threading necessária.
- RNF02: O header CSV deve continuar o mesmo — os campos raw de D01 e D02 combinados.
- RNF03: Se D01 chegar mas D02 nunca chegar (conexão perdida), o buffer deve ser descartado automaticamente quando um novo D01 chegar.

## Especificações Técnicas

### Formato da linha CSV atual

O header atual em `Worker.__init__` lista 35 colunas:
```
Timestamp; Event; Mess 1; RPM; MAP; Boost; Load %; Idle; Lambda 1; Inj. Pulse;
Inj. Utiliz.; VE Value; Ign. Adv.; Knock; A/C Input; Start Input; Outputs 1; Outputs 2;
Lambda 2; Mess 2; Batt Volt.; CLT; IAT; Inj. DT; Ign. Dwell; KM/H; Lambda Loop; Lambda Target;
Lambda Corr; Strobo Angle; Turbo Target; ACC %; ACP %; dACC %; 0; 0
```

O método `write()` atual faz:
```python
parts = line.split(";")
self.task.emit([timestamp, event] + parts)
```

Onde `line` é `"#D01;v1;v2;...;#D02;v19;v20;..."` — a string combinada. Com frames separados, o novo código fará:

```python
d01_parts = d01_line.split(";")   # ["#D01", v1, v2, ...]
d02_parts = d02_line.split(";")   # ["#D02", v19, v20, ...]
self.task.emit([timestamp, event] + d01_parts + d02_parts)
```

Isso produz o mesmo resultado desde que os campos de D01 e D02 sejam concatenados na mesma ordem do formato combinado atual.

        from app.event.app_events import AppEventType
        event_bus.subscribe(AppEventType.ECU_MESS_FRAME, self._on_mess_frame)
        event_bus.subscribe(AppEventType.EVENT_MARK_REQUESTED, lambda _: self.set_event_pending())

    def _on_mess_frame(self, event: EcuMessFrameEvent):
        if event.frame_id == "D01":
            if self._d01_buffer is not None:
                logger.warning("D01 recebido sem D02 anterior — descartando frame anterior")
            self._d01_buffer = event.raw_line
        elif event.frame_id == "D02":
            if self._d01_buffer is None:
                logger.warning("D02 recebido sem D01 — descartando")
                return
            d01 = self._d01_buffer
            self._d01_buffer = None
            self._write_combined(d01, event.raw_line)

        d02_parts = d02_line.split(";")
        self.task.emit([timestamp, event] + d01_parts + d02_parts)

        self._event_pending = True

### Subscrição de EVENT_MARK_REQUESTED

Em `main.py` atual:
```python
event_bus.subscribe(AppEventType.EVENT_MARK_REQUESTED, lambda _: log_writer.set_event_pending())
```

Com esta história, a subscrição é movida para dentro do `LogWriter.__init__()`, eliminando a necessidade de fazer no `main.py`. A subscrição em `main.py` deve ser removida em HIST-10.
